brand_outlet.tm — готовая версия на основе загруженного Luxury watch template.

Что подключено:
- главная и каталог
- товары из Firestore collection "watches"
- поиск
- страница товара
- корзина
- избранное
- оформление заказа
- коллекция "orders"
- авторизация Firebase
- аккаунт
- глобальные темы через localStorage
- цены TMT

Перед публикацией:
1) В Firebase Authentication включите Email/Password.
2) Проверьте Firestore Rules для чтения watches и создания orders.
3) Оставьте существующую admin.html отдельно, если она уже есть.
